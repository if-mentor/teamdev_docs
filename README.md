# React / Next.js Team Development Document

**開発にあたりこちらの README を必ずご一読ください。**\
**開発の進め方やルール等につきましては、こちらに記載されています。**

## 目的

**React / Next.js を用いた Web アプリケーションのチーム開発を通じて、Git / GitHub を活用した開発手法や、チーム開発に必要な基本的な技術・スキルの習得を目指します。**

以下の項目を習得することを目的とします。

- Git / GitHub を活用したバージョン管理
- Git の基本操作（clone、add、commit、push、pull、branch、merge など）
- ブランチを活用したチーム開発
- Pull Request を活用したコードレビュー
- GitHub Flow に基づく開発フロー
- チーム開発におけるコーディング規約
- コンフリクト（競合）の発生原因と解決方法

## スケジュール

| 期間  | 内容 |
| --- | --- |
| 5Week | [開発](DEVFLOW.md) |

週次でミーティングを開催いたします。**原則として、全員参加でお願いいたします。**\
※ プライベートなどの都合で参加が難しい場合もあると思いますので、その際はチーム開発チャンネルにご連絡ください。\
※ 臨時のミーティングやチームメンバー同士でのもくもく会については、自由に開催していただいて問題ございません。
